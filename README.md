# SALES PERFORMANCE DASHBOARD

An interactive Sales Performance Dashboard developed using **Microsoft Power BI Desktop** to analyze business performance through key performance indicators (KPIs), regional sales distribution, quarterly trends, product categories, and sales target achievement.

The dashboard combines data analysis with interactive visualizations to present sales performance in a clear and accessible format.

## 📌 Project Overview

This project focuses on analyzing sales performance using an interactive Power BI dashboard.

The dashboard provides an overview of business performance through KPI cards, regional comparisons, quarterly sales analysis, category-based filtering, and a sales target achievement gauge.

The design uses an orange and purple color theme to create a distinctive visual identity while keeping the analytical elements easy to interpret.

## 📉 Dashboard Features

### 1. Regional Sales Analysis
- Compares sales performance across East, North, West, and South regions.
- Uses a column chart to visualize regional sales distribution.
- Helps identify regions contributing more to overall sales.

### 2. Quarterly Sales Analysis
- Visualizes sales performance across Q1, Q2, Q3, and Q4.
- Highlights quarterly sales trends.
- Makes it easier to compare performance between quarters.

### 3. Product Category Filtering

Interactive category slicer allows users to filter the dashboard by:
- Apparel
- Electronics
- Furniture
- Home & Kitchen
- Stationery

### 4. Monthly Filtering
- Includes a month-based filter covering all twelve months.
- Allows users to explore sales performance for individual months.

### 5. Sales Target Achievement
- Includes a gauge visualization to compare actual sales against a sales target.
- Current sales: $2.31M
- Target reference: $3M
- Sales target achievement: Approximately 77%

These calculations support dynamic reporting and respond to the dashboard's interactive filters.
